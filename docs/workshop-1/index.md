# 1. Code-along: Build your first app with coding agents

<p class="meta">10:00–12:00 · Main hall · บังคับทุกคน</p>

ทุกคนจะได้ build feature ด้วย coding agent บนเครื่องของตัวเอง แล้ว merge งานของทั้งทีมเป็น app เดียวบน GitHub

## สิ่งที่จะได้เรียน

- Run app บน iPad ของตัวเอง
- ใช้ Git และ GitHub ตั้งแต่ commit จนถึง pull request
- ใช้ **Xcode agents** (Mac M chip) หรือ **OpenCode** (ทุกเครื่อง)
- เขียน prompt ที่ดี และใช้ agent อย่างปลอดภัย

## Team challenge

1. แต่ละคนเลือก feature ที่ไม่ซ้ำกัน: search, dark mode, share button, settings screen หรือ animation
2. สร้าง branch ของตัวเอง เช่น `feature/search`
3. ใช้ agent ของตัวเอง build feature แล้ว run บน iPad
4. 8 นาทีสุดท้าย: merge ทุก branch เข้า `main` แก้ conflict แล้ว run บน iPad ทุกเครื่อง

## Exit checklist

- [ ] Run app บน iPad ของตัวเองได้
- [ ] Commit และ push งานของตัวเองอย่างน้อย 1 ครั้ง
- [ ] Build feature ด้วย coding agent สำเร็จ
- [ ] ทีม merge ทั้ง 3 branch เข้า `main` และเปิด pull request อย่างน้อย 1 อัน
